# 🏋️ Gym Management System

A full-stack Gym Management System built using React, Spring Boot, MySQL, and Docker.

## Features

- Member Management
- Trainer Management
- Attendance Tracking
- Payment Management
- AI Diet Plan Generator
- REST APIs
- Dockerized Deployment

## Tech Stack

### Frontend
- React
- Vite
- Axios

### Backend
- Spring Boot
- Spring Data JPA
- Hibernate
- Java 21

### Database
- MySQL 8

### DevOps
- Docker
- Docker Compose

## Project Structure

```
Gym-Management-System
```
